1

ติดตั้ง Node.js

เครื่องคุณยังไม่มี Node ซึ่งเป็นตัวรันเครื่องมือแปลงโค้ด ติดตั้งครั้งเดียวใช้ได้ตลอด

  1. เปิด nodejs.org กดปุ่มดาวน์โหลดฝั่งซ้ายที่เขียนว่า LTS
  2. เปิดไฟล์ .pkg ที่ดาวน์โหลดมา กด Continue ไปเรื่อยๆ จนจบ
  3. เปิดแอป Terminal (กด ⌘+Space พิมพ์ terminal) แล้วรันคำสั่งนี้เพื่อตรวจ
node -v
npm -v

ต้องขึ้นเลขเวอร์ชันทั้งสองบรรทัด เช่น v22.14.0 และ 10.9.2 ถ้าขึ้น command not found ให้ปิด Terminal แล้วเปิดใหม่

2

ติดตั้งไลบรารีของโปรเจกต์

cd ~/Desktop/supplier-bidding/app
npm install

ใช้เวลา 1–2 นาที จะมีโฟลเดอร์ node_modules เพิ่มขึ้นมา ถ้ามีคำเตือนสีเหลือง (warn) ไม่เป็นไร ข้ามได้

3

สร้างโปรเจกต์ Supabase

  1. เปิด supabase.com → Start your project → สมัครด้วย GitHub หรืออีเมล
  2. กด New project ตั้งชื่อ cjx-bidding
  3. ตั้ง Database Password แล้วเก็บไว้ในที่ปลอดภัย (ใช้ตอนต่อฐานข้อมูลตรง)
  4. Region เลือก Southeast Asia (Singapore) — สำคัญ เพราะใกล้ไทยที่สุด
  5. กด Create แล้วรอประมาณ 2 นาที
ห้ามเลือก region อื่น ถ้าเลือกอเมริกา/ยุโรป การกดหยอดราคาจะหน่วงขึ้นเห็นได้ชัด และย้าย region ทีหลังไม่ได้ ต้องสร้างโปรเจกต์ใหม่
4

รันไฟล์ SQL 4 ไฟล์ ตามลำดับ

ในหน้า Supabase เลือกเมนู SQL Editor → New query → เปิดไฟล์จากโฟลเดอร์ app/supabase/ คัดลอกทั้งไฟล์ไปวาง แล้วกด Run ทำทีละไฟล์ตามลำดับนี้

  1. 01_schema.sql — สร้างตารางทั้งหมด
  2. 02_rls.sql — กติกาการมองเห็นราคา
  3. 03_functions.sql — ฟังก์ชันยื่นราคา เปิดซอง ประกาศผล ค้อน
  4. 04_storage.sql — ที่เก็บไฟล์แนบ
ต้องขึ้น Success ทุกไฟล์ ถ้าไฟล์ไหน error ให้หยุดก่อน อย่ารันไฟล์ถัดไป เพราะไฟล์หลังอ้างถึงของในไฟล์หน้า
5

สร้างผู้ใช้

เมนู Authentication → Users → Add user → Create new user

  1. สร้าง 1 บัญชีสำหรับฝ่ายจัดซื้อ และ 1 บัญชีต่อ 1 ซัพพลายเออร์ (เริ่มด้วย 3 ราย)
  2. กรอกอีเมล + รหัสผ่าน และ ติ๊ก Auto Confirm User ทุกครั้ง
  3. คลิกที่ผู้ใช้แต่ละคน คัดลอก UID (เลขยาวๆ) เก็บไว้ทั้ง 4 ค่า
ถ้าไม่ติ๊ก Auto Confirm จะเข้าสู่ระบบไม่ได้และขึ้นว่าอีเมลหรือรหัสผ่านไม่ถูกต้อง ซึ่งเป็นปัญหาที่เจอบ่อยที่สุด
6

ใส่ข้อมูลตั้งต้น

  1. เปิดไฟล์ app/supabase/05_seed.sql ด้วย TextEdit
  2. แก้ UUID 4 บรรทัดบนสุด ให้ตรงกับ UID ที่คัดลอกไว้ในขั้นที่ 5
  3. คัดลอกทั้งไฟล์ไปวางใน SQL Editor แล้วกด Run

จะได้บริษัทผู้ขาย 3 ราย โปรไฟล์ผู้ใช้ 4 คน และประกาศตัวอย่าง 2 งาน (เปิดราคา 1 / ปิดราคา 1)

เอาโค้ดขึ้น GitHub

  1. เปิด github.com สมัคร (ฟรี) → กด New repository
  2. ตั้งชื่อ cjx-bidding เลือก Private แล้วกด Create — อย่า ติ๊ก add README
  3. กลับมาที่ Terminal รันคำสั่งด้านล่าง (แก้ ชื่อบัญชี เป็นชื่อ GitHub ของคุณ)
cd ~/Desktop/supplier-bidding
git init
git add .
git commit -m "ระบบประมูลจัดซื้อ CJx"
git branch -M main

ไฟล์ .env ไม่ถูกอัปขึ้น GitHub เพราะมี .gitignore กันไว้แล้ว คีย์ของคุณจะไม่หลุด เดี๋ยวไปใส่ในหน้า Cloudflare แทน

ถ้า git ยังไม่มีในเครื่อง macOS จะเด้งถามให้ติดตั้ง Command Line Tools กด Install แล้วรอ · ถ้าถามรหัสผ่านตอน push ให้ใช้ Personal Access Token จาก GitHub → Settings → Developer settings ไม่ใช่รหัสผ่านบัญชี

สร้างโปรเจกต์บน Cloudflare Pages

  1. เปิด dash.cloudflare.com สมัคร (ฟรี ไม่ต้องผูกบัตร)
  2. เมนูซ้าย Workers & Pages → Create → Pages → Connect to Git
  3. อนุญาตให้ Cloudflare เห็น repo cjx-bidding แล้วเลือก repo นั้น
  4. กรอกค่า build ตามตารางนี้ให้ตรงทุกช่อง

app

ผูกโดเมนบริษัท (ถ้าต้องการ)

  2. ใส่ชื่อที่ต้องการ เช่น bidding.cjmart.co.th
  3. Cloudflare จะบอกค่า CNAME ที่ต้องเพิ่ม ส่งให้ทีม IT เพิ่มใน DNS ของบริษัท

ใบรับรอง HTTPS ออกให้อัตโนมัติฟรี ใช้ได้ภายในไม่กี่นาทีหลัง DNS อัปเดต

ต่อไปถ้าจะแก้ ต้องทำอะไร

มี 3 แบบ แยกกันชัดเจน เลือกตามสิ่งที่จะแก้

แบบ 1 · แก้หน้าเว็บ

ข้อความ สี ขนาด เปอร์เซ็นต์ปุ่ม เพิ่ม/ลดช่องในฟอร์ม

  1. แก้ไฟล์ในโฟลเดอร์ app/src
  2. ทดสอบในเครื่อง npm run dev
  3. ส่งขึ้น GitHub 3 คำสั่ง (ด้านล่าง)
  4. Cloudflare build ใหม่เองอัตโนมัติ ~1 นาที
แบบ 2 · แก้กติกา

ใครเห็นราคาเมื่อไร กติกาค้อน รูปแบบเลขที่งาน เงื่อนไขการยื่น

  1. แก้ไฟล์ใน app/supabase/
  2. คัดลอกเฉพาะฟังก์ชันที่แก้ ไปวางใน SQL Editor แล้ว Run
  3. มีผลทันที ไม่ต้อง deploy หน้าเว็บ
  4. push ขึ้น GitHub ด้วย เพื่อไม่ให้ไฟล์กับของจริงต่างกัน
แบบ 3 · แก้ข้อมูล

เพิ่มบริษัทผู้ขาย เพิ่มผู้ใช้ แก้ชื่อ แก้เลขผู้เสียภาษี ลบงานทดสอบ

  1. Supabase → Table Editor
  2. เลือกตาราง เช่น suppliers แล้วกด Insert row
  3. ผู้ใช้ใหม่: Authentication → Add user ก่อน แล้วเพิ่มแถวใน profiles
  4. ไม่ต้องแตะโค้ดเลย

ปัญหาที่เจอบ่อย

อาการสาเหตุวิธีแก้
ขึ้นว่า “ยังไม่ได้ตั้งค่า VITE_SUPABASE_URL”ไม่มีไฟล์ .env หรือชื่อตัวแปรผิดตรวจว่าไฟล์ชื่อ .env อยู่ในโฟลเดอร์ app แล้วปิด npm run dev เปิดใหม่
เข้าสู่ระบบไม่ได้ บอกว่าอีเมลหรือรหัสผ่านไม่ถูกต้องตอนสร้างผู้ใช้ไม่ได้ติ๊ก Auto ConfirmAuthentication → คลิกผู้ใช้ → Confirm email หรือลบแล้วสร้างใหม่ให้ติ๊กด้วย
เข้าสู่ระบบผ่าน แต่ขึ้นว่าโหลดข้อมูลผู้ใช้ไม่ได้ยังไม่มีแถวใน profilesรัน 05_seed.sql หรือเพิ่มแถวใน Table Editor ให้ UUID ตรงกับผู้ใช้
ซัพพลายเออร์เห็นรายการงานว่างเปล่ายังไม่ได้เชิญบริษัทนั้นเข้างานล็อกอินเป็นฝ่ายจัดซื้อ สร้างประกาศแล้วติ๊กเชิญบริษัทนั้น
อัปโหลดไฟล์ขึ้น error violates row-level securityยังไม่รัน 04_storage.sqlรันไฟล์นั้นใน SQL Editor แล้วลองใหม่
ราคาไม่ขึ้นเรียลไทม์ตาราง bids ยังไม่เข้า publicationรันบรรทัดท้ายของ 01_schema.sql ที่เป็น alter publication ซ้ำอีกครั้ง
Cloudflare build fail หา package.json ไม่เจอไม่ได้ตั้ง Root directorySettings → Builds → Root directory ใส่ app แล้ว Retry deployment
เว็บขึ้นหน้าขาวลืมใส่ env vars ใน Cloudflareใส่ 2 ตัวแล้วกด Retry deployment (ต้อง build ใหม่ค่าจึงมีผล)
ระบบใช้งานไม่ได้หลังหยุดใช้นานหลายวันโปรเจกต์ Supabase ฟรีถูก pause หลังไม่มีการใช้งาน 7 วันเข้า Supabase กด Restore project ใช้ได้ตามปกติ ถ้ามีคนใช้ทุกวันจะไม่โดน

ถ้าเจออาการอื่น ให้คัดลอกข้อความ error ทั้งบรรทัด (จาก Terminal หรือ Console ในเบราว์เซอร์) มาถามได้เลย
